# BibliotecaSimples

Este é um projeto Java simples que simula uma biblioteca. Nele, é possível adicionar livros e listá-los utilizando uma estrutura de classes com `Livro` e `Biblioteca`.

## Funcionalidades
- Adicionar livro (título e autor)
- Listar livros adicionados
